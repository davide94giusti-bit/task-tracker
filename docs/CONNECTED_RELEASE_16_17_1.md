# Connected release 16.17.1

Deadline Pressure now appears only in the collapsible Dashboard card. Calendar no longer requests a pressure snapshot and no longer shows pressure dots, the pressure legend, or the Daily/Weekly pressure card beneath the month grid.

Calendar continues to show its existing task/checklist-derived day cards, priority/completion severity, and unique parent-task counts. Checklist dates and completed-item filtering are unchanged.

This release has no database migration or Worker API change. The service-worker cache advances to 16.17.1 so installed PWAs receive the revised Calendar.
