# Task Tracker Connected v16.14.0 — flexible schedules and tracked milestones

This release adds recurring task reminders, optional dates on checklist items, and an opt-in rule that completes a task when all of its active checklist items are finished. Reopening or adding an item reopens a task that was completed by that rule.

Task costs now have an independent cost date. Financial analysis uses the cost date first and falls back to completion, due, then creation date, so paid work remains reportable even when the task has no deadline.

New invitees choose a display name while creating their password; their email remains the sign-in identifier. Shared-project collaborators who can manage checklist items can also set checklist dates.

The user manual has updated explanations and consistently rendered, direction-aware numbered annotations.
